# Hermes Agent e Grok Bot para o fluxo do Curador

## O que importa

Pergunta dela: se o Hermes Agent e o Grok Bot seriam bons para o nosso fluxo. Recomendação do Curador: nenhum dos dois agora.

- **Hermes Agent (Nous Research):** agente de código aberto que você mesmo hospeda, com memória própria (`~/.hermes/memories/`), skills que ele escreve sozinho, rotinas e cerca de 20 canais de mensagem (WhatsApp, Telegram, Slack, e-mail). Repete o que o vault, as skills e as rotinas do Maestri já fazem, e criaria uma segunda memória fora do vault. Ganho real: falar com o Curador pelo celular. Usa a API cobrada por uso; se aceita a assinatura do Claude, não confirmado. Os números de desempenho são da própria Nous Research.
- **Grok Bot (xAI):** agentes que ficam sempre ligados, cada um com um computador próprio na nuvem, em beta desde 11/08/2026, segundo blogs. Faz o papel das sessões do Claude Code na nuvem que já usamos. Exigiria refazer papéis e skills para outro modelo e dar acesso amplo a um produto em beta. Não achei página oficial da xAI que confirme recursos e preço; a fusão com o Cursor aparece numa fonte só.
- **Quando olhar de novo:** se ela quiser falar com o Curador pelo celular (pesquisar antes se o Maestri ou o Claude Code já fazem isso), ou se a cota do Claude virar um gargalo constante.
- Ela não disse ainda o que a fez pensar no Hermes.
